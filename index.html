Skylera Design System

Token warna, komponen dasar, dan aturan tema light/dark untuk website company profile Skylera Corporation. Semua pasangan warna diaudit terhadap WCAG 2.2 AA.

Mulai pakai Lihat audit kontras

Prinsip

Disusun dari WCAG 2.2, IBM Carbon, Radix Colors, dan Material Design.

  • Token semantic, bukan hexKomponen hanya memakai token peran seperti --sk-text-primary. Nilainya berganti per tema, namanya tetap.
  • Kontras terverifikasiTeks minimal 4.5:1, border input dan focus ring minimal 3:1. Dicek otomatis di bagian Aksesibilitas.
  • Link di paragraf selalu underlineWarna link hampir sama terang dengan teks biasa, jadi warna saja tidak cukup (WCAG 1.4.1).
  • Satu warna aksi: tealTombol primary adalah CTA utama, maksimal satu per layar. Amber hanya untuk status warning, karena materi brand tidak memakai amber.
  • Dark-first, bukan hitam pekatDark adalah tema default, mengikuti visual brand di Instagram. Latarnya abu-abu gelap bernuansa teal, dan elevasi ditunjukkan dengan surface yang lebih terang.
  • Teal brand tetap di kedua temaPakai .sk-brand-band untuk hero dan section brand supaya focus ring dan link ikut menyesuaikan.

Audit kontras

Dihitung langsung dari token dengan rumus WCAG 2.2, untuk setiap permukaan tempat warna itu bisa muncul. Teks minimal 4.5:1; border input dan focus ring minimal 3:1 (SC 1.4.11). State disabled dikecualikan oleh WCAG.

Pemakaian

Muat ketiga file di <head>. Script tema harus sinkron (tanpa defer) supaya tidak ada kedipan saat halaman dibuka.

<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="components.css">
<script src="theme-toggle.js"></script>

Toggle tema

<!-- Default dark. Pilihan: dark, light, atau ikut setting perangkat -->
<button data-sk-theme-set="dark">Dark</button>
<button data-sk-theme-set="light">Light</button>
<button data-sk-theme-set="system">Sistem</button>

<!-- Atau satu tombol tukar light/dark -->
<button data-sk-theme-toggle>Ganti tema</button>

Memakai token di CSS sendiri

.testimonial {
  background: var(--sk-bg-surface);
  border: 1px solid var(--sk-border);
  color: var(--sk-text-secondary);
}

Aturan

  • Jangan pakai hex atau token primitive (--sk-teal-500) langsung di komponen. Kalau belum ada token yang pas, tambah token semantic baru lalu cek kontrasnya di halaman ini.
  • Link di dalam paragraf pakai .sk-link (underline). Link navigasi dan tombol tidak perlu underline.
  • Satu .sk-btn--primary per layar sebagai CTA utama. Aksi lain pakai secondary. Di dalam .sk-brand-band, primary otomatis berganti ke versi terang.
  • Logo: pakai assets/logo - no bg.svg di light dan assets/logo - no bg white.svg di dark, atau inline SVG dengan color: var(--sk-logo).
  • Tipografi, spacing, dan radius di tokens.css masih sementara dan belum diriset seperti warna.
